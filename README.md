## О программе

**Pallet Sheet Generator** автоматизирует подготовку паллетного листа по готовому шаблону. Пользователь заполняет сведения о продукции и паллете, проверяет сформированный штрих-код в области предпросмотра и получает готовый файл `.docx`.

Приложение создано для практического производственного сценария, где важны скорость заполнения, единообразие документов и сохранение верстки шаблона.

> [!NOTE]
> Репозиторий содержит готовую сборку программы. Исходный код в этой публикации не размещён.

## Возможности

| Функция | Что делает |
|---|---|
| Штрих-код | Формирует штрих-код по введённому цифровому номеру и показывает его в предпросмотре |
| Данные продукции | Добавляет код и наименование продукта, производителя и количество коробов |
| Даты | Заполняет дату закрытия паллеты и срок годности |
| Шаблон 1:1 | Сохраняет исходную компоновку паллетного листа при подстановке новых значений |
| Экспорт DOCX | Создаёт готовый документ с выбранным именем в указанной папке |
| Быстрые действия | Позволяет открыть папку сохранения или сразу перейти к созданному DOCX |

## Быстрый старт

1. Скачайте [`PalletSheetGenerator.rar`](./PalletSheetGenerator.rar).
2. Распакуйте архив в отдельную папку, сохранив его внутреннюю структуру.
3. Запустите исполняемый файл приложения в Windows.
4. Заполните номер штрих-кода и сведения о продукции.
5. Укажите количество коробов, дату закрытия паллеты и срок годности.
6. Выберите папку сохранения и имя будущего файла.
7. Проверьте предпросмотр и нажмите **«Сгенерировать DOCX»**.
8. Перед печатью визуально проверьте сформированный документ.

## Рабочий процесс

> **Путь документа:** данные паллеты → генерация штрих-кода → предпросмотр → готовый DOCX.
